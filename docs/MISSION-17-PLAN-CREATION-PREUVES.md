# Mission 17 — Plan de création des preuves

Date : 24 juillet 2026

## Principe

Une preuve n’est publiable que si elle est :

- issue d’un dossier ou d’une expérience réelle ;
- exacte et suffisamment contextualisée ;
- autorisée par la personne ou l’entreprise concernée ;
- compatible avec la confidentialité et le secret professionnel applicable ;
- datée ;
- conservée avec son justificatif ;
- présentée sans transformer un cas particulier en promesse générale.

Aucune preuve ne doit être créée pour remplir une maquette ou soutenir une campagne.

## Registre interne des preuves

Créer un registre non public avec les colonnes suivantes :

| Champ | Contenu attendu |
|---|---|
| Identifiant | Code interne sans nom de client |
| Type | Cas, avis, témoignage, FAQ, comparatif, résultat |
| Dossier source | Référence interne sécurisée |
| Responsable | Personne qui vérifie l’exactitude |
| Faits utilisables | Éléments objectivement démontrables |
| Éléments interdits | Données confidentielles ou non autorisées |
| Autorisation | Date, périmètre, support et durée |
| Anonymisation | Méthode et contrôle |
| Validation métier | Nom, rôle et date |
| Validation juridique/RGPD | Requise ou non, décision |
| Date de publication | À renseigner |
| Date de revue | À renseigner |
| Statut | Candidat, en validation, autorisé, publié, retiré |

Le registre ne doit pas être stocké dans le dépôt public s’il contient des informations de dossier ou des données personnelles.

## 1. Études de cas

### Format recommandé

1. contexte de l’entreprise, limité aux informations autorisées ;
2. événement déclencheur ;
3. documents analysés ;
4. incohérence ou question identifiée ;
5. méthode suivie ;
6. décision prise par le client ;
7. résultat observable ;
8. limites et éléments non généralisables.

### Cas prioritaires

- audit global d’une PME avant renouvellement ;
- entreprise de transport avec plusieurs objets de risque à distinguer ;
- flotte dont les usages, conducteurs ou mouvements nécessitaient une meilleure présentation ;
- entreprise BTP avec activités multiples ou attestation à rapprocher des travaux ;
- décision de conserver un contrat lorsque la remise en concurrence n’était pas pertinente.

### Validation

- accord écrit de publication ;
- choix explicite entre nom, anonymisation partielle et anonymisation totale ;
- validation de toute donnée chiffrée ;
- aucune mention d’un assureur ou partenaire sans autorisation ;
- aucun résultat présenté comme reproductible.

## 2. Avis

### Méthode

- demander un avis après une interaction réelle suffisamment aboutie ;
- utiliser le lien officiel Google si la fiche est éligible et vérifiée ;
- ne pas sélectionner uniquement les clients supposés satisfaits selon un critère caché ;
- ne proposer aucune remise, cadeau ou avantage ;
- répondre de manière sobre et individualisée ;
- ne jamais rédiger l’avis à la place du client.

Google exige que les avis reflètent une expérience réelle et interdit les incitations :

<https://support.google.com/business/answer/3474122>

### Message de demande

Le message doit :

- rappeler l’interaction concernée ;
- préciser que l’avis est facultatif ;
- ne suggérer ni note ni formulation ;
- fournir un seul lien ;
- indiquer qu’aucune contrepartie n’est proposée.

## 3. Témoignages

### Différence avec un avis

Un témoignage est choisi et publié par Assuromieux sur un support contrôlé. Il exige donc une autorisation plus précise que l’avis laissé spontanément sur une plateforme.

### Autorisation minimale

- texte exact validé ;
- identité et fonction affichées, ou anonymisation choisie ;
- nom et logo de l’entreprise autorisés séparément ;
- supports : site, LinkedIn, email, présentation ;
- durée ;
- droit de retrait et contact ;
- date de l’expérience.

### Interdictions

- corriger le sens du propos ;
- transformer une satisfaction en promesse de résultat ;
- utiliser un témoignage ancien sans date ;
- inventer une fonction, une société ou un secteur.

## 4. FAQ

La FAQ est une preuve d’expérience lorsqu’elle provient de questions réellement posées.

### Processus

1. consigner les questions reçues en rendez-vous, email ou formulaire ;
2. regrouper les variantes ;
3. compter les occurrences sans enregistrer de données nominatives ;
4. choisir les questions qui aident à décider ;
5. rédiger une réponse prudente ;
6. faire relire le point métier ;
7. publier sur la page la plus pertinente ;
8. revoir tous les six mois.

### Priorités

- que reçoit l’entreprise après un audit ;
- audit ou mise en concurrence ;
- documents à préparer ;
- délai avant échéance, sans promettre un délai universel ;
- articulation Flotte, RC transporteur et marchandises ;
- activités déclarées en décennale ;
- RC professionnelle et RC exploitation ;
- garanties Cyber et mesures de sécurité.

## 5. Comparatifs

### Comparatifs autorisés

- grille neutre de garanties, limites, franchises, exclusions et services ;
- comparaison d’objets de risque : véhicule, responsabilité, marchandises ;
- comparaison de méthodes : prix seul versus programme homogène ;
- tableau de documents à réunir selon le besoin.

### Comparatifs à éviter

- classement public d’assureurs sans méthodologie robuste et droits nécessaires ;
- affirmation « meilleur contrat » ;
- tarifs non comparables ;
- notation opaque ;
- comparaison fondée sur un exemple inventé.

Chaque comparatif doit afficher :

- périmètre ;
- date ;
- critères ;
- sources ;
- limites ;
- relecteur.

## 6. Résultats

### Résultats potentiellement publiables

- dossier consolidé ;
- incohérence documentée puis corrigée ;
- décision comprise et tracée ;
- consultation menée sur un périmètre homogène ;
- contrat conservé après analyse ;
- processus de renouvellement mieux préparé.

### Résultats chiffrés

Un chiffre n’est utilisable que si :

- le calcul est reproductible ;
- la période et le périmètre sont précisés ;
- les éléments comparés sont homogènes ;
- les coûts transférés vers franchises ou exclusions sont pris en compte ;
- l’autorisation est écrite ;
- le résultat n’est pas présenté comme une garantie.

Éviter de faire de l’économie de prime le résultat principal. Une baisse de prime peut masquer une réduction de garanties ou un déplacement du risque.

## Calendrier sur six mois

| Mois | Action | Sortie attendue |
|---:|---|---|
| 1 | Créer le registre et les modèles d’autorisation | Processus prêt, aucune publication |
| 2 | Identifier cinq dossiers candidats et dix FAQ réelles | Liste interne qualifiée |
| 3 | Demander les premières autorisations ; solliciter des avis réels | Preuves autorisées ou refus consignés |
| 4 | Rédiger un premier cas et un comparatif méthodologique | Brouillons relus |
| 5 | Publier au maximum un cas et intégrer des FAQ | Preuves datées et reliées aux pages |
| 6 | Auditer autorisations, exactitude, résultats et retrait | Décision maintenir, corriger ou retirer |

## Critères avant publication

- [ ] dossier réel ;
- [ ] faits vérifiés ;
- [ ] autorisation archivée ;
- [ ] confidentialité contrôlée ;
- [ ] formulation non généralisante ;
- [ ] aucune promesse automatique ;
- [ ] source et date présentes ;
- [ ] relecteur identifié ;
- [ ] page de destination cohérente ;
- [ ] date de revue prévue.
